# The Retraction Epidemic in Science Across Publishers, Fields, and Countries

Repository for the code and analysis in the paper 'The Retraction Epidemic in Science Across Publishers, Fields, and Countries' by Sara Venturini, Alessandra Urbinati, Paola Gallo, Jessica T. Davis, Alessandro Vespignani

Requirments 
- `requirements.txt`

Data (in the paper downloaded in Oct 2025)

- OpenAlex snapshot : https://openalex.s3.amazonaws.com/browse.html
- Retraction Watch Database : https://gitlab.com/crossref/retraction-watch-data 

Jupyter notebooks
- `BigqueryTablesCreation.ipynb` : creates BigQuery tables from the OpenAlex snapshot
- `Retraction.ipynb` : contains all analyses used in the paper, organized by category (works, domains, fields, countries, publishers, authors)
