# The Retraction Epidemic in Science Across Publishers, Fields, and Countries

Repository for the code and analysis in the paper 'The Retraction Epidemic in Science Across Publishers, Fields, and Countries' by Sara Venturini, Alessandra Urbinati, Paola Gallo, Jessica T. Davis, Alessandro Vespignani

Requirments 
- `requirements.txt`

Data

- OpenAlex snapshot (in the paper updated Oct 2025): https://openalex.s3.amazonaws.com/browse.html
- Retraction Watch Database (in the paper downloaded Oct 2025): //gitlab.com/crossref/retraction-watch-data

Jupyter notebooks
- `BigqueryTablesCreation.ipynb` : creation Bigquery tables from OpenAlex snapshot
- `Retraction.ipynb` : analysis performed in the paper divided by categories (works, domains, fields, countries, publishers, authors)
